# Embedded-V4L2-Camera-System
项目名称：基于V4L2框架的嵌入式Linux相机模块开发
项目描述：面向嵌入式 Linux 平台的摄像头图像采集与显示需求，基于 V4L2 框架实现完整的相机应用模块。
工作内容：
1. 基于V4L2框架完成摄像头设备初始化、视频格式查询与配置、采集参数设置等流程，实现对USB或MIPI摄像头的支持
2. 采用 MMAP 内存映射方式管理视频缓冲区，实现帧数据的零拷贝采集，降低 CPU 搬运开销
3. 实现 YUV 到 RGB 图像格式转换算法，并结合图像缩放算法 PicZoom 适配不同分辨率显示设备
4. 基于 Linux Framebuffer 子系统完成图像输出显示，实现采集到显示的完整链路
5. 集成 MJPG-Streamer 实现基于 HTTP 的网络视频流推送
6. 基于 LVGL 图形界面库开发相机应用界面
